> 이 파일의 역할: 홍보 모션 영상(모바일 기준)에 쓰는 화면 규격, 색, 글꼴, 배경, 모티프, 소재 목록의 기준표입니다.

# 모션 영상 디자인 기준

- 출처: Figma `수원시립미술관포털-홍정민` → `3-6. 모션` 페이지, 프로젝트 `src/styles/tokens.css`·`typography.css`
- 장면 구성은 [`아이디어.md`](./아이디어.md)를 따릅니다. 이 문서에는 장면 내용과 움직임을 쓰지 않습니다.

## 1. 화면 규격

| 항목 | 값 | 상태 |
| :--- | :--- | :--- |
| 화면 방향 | 가로 | 확정 |
| 해상도 | 1920 × 1080 (16:9) | 확정 |
| fps (1초에 보여 주는 장면 수) | 30fps | 확정 |
| 영상 길이 | 30초 | 확정 |
| 원본 화면 크기 | 360 × 834 (Figma 모바일 화면, 세로) | 확정 |
| 화면 확대 배율 | 1.2배보다 조금 작음 (휴대폰 틀 크기가 정해지면 계산) | [확인 필요] |
| 화면 배치 방식 | 휴대폰 틀에 넣기 | 확정 |

가로 영상 가운데에 세로 휴대폰 틀을 놓고, 그 안에 모바일 화면을 넣습니다. 틀의 테두리와 위아래 여백만큼 화면 배율이 1.2배보다 작아집니다.

## 2. 브랜드 컬러

프로젝트에는 따로 정한 "대표 색"이 없고, 무채색 위주에 파랑과 초록을 강조색으로 씁니다. 아래 HEX 값은 모두 Figma 변수와 같습니다.

| 이름 (Figma 변수) | HEX | 화면에서의 용도 | 영상 용도 제안 |
| :--- | :--- | :--- | :--- |
| Page&Container/Back | `#FFFFFF` | 화면 배경, 버튼 배경 | 기본 배경 |
| Cards/Back_back | `#F1EFE8` | 카드 뒷배경 | 보조 배경 [확인 필요] |
| Page&Container/Stroke · Cards/Stroke | `#D3D1C7` | 구분선, 카드 테두리 | 구분선 |
| Buttons/Stroke · Input Fields/Stroke | `#888780` | 버튼·입력칸 테두리 (선 전용) | 선 전용, 글자에는 쓰지 않음 |
| Page&Container/Text_address | `#5F5E5A` | 현재 위치, 흐린 글자 | 보조 글자 |
| Page&Container/Text_sub | `#444441` | 본문 보조 글자 | 보조 글자 |
| Page&Container/Text | `#1F1F1E` | 제목·본문 글자 | 기본 글자 |
| Black | `#1A1A1A` | 검은 버튼 (`Apply`, `Submit Reservation`, 선택된 탭) | 강조 버튼 |
| GNB&LNB/Info_text | `#185FA5` | 안내 문구 글자, 라디오 선택 | 강조색 1 [확인 필요] |
| GNB&LNB/Info_back | `#E6F1FB` | 안내 영역 배경 | 강조 배경 [확인 필요] |
| Cards/Tag_text | `#085041` | 카드 태그 글자 (`Child` 등) | 강조색 2 [확인 필요] |
| Cards/Tag_back | `#E1F5EE` | 카드 태그 배경 | 강조 배경 [확인 필요] |
| Icon/Icon | `#1D9E75` | 아이콘 (완료 표시 등) | 완료·성공 표시 |
| Input Fields/Special_Text | `#A32D2D` | 필수 표시(*), 오류 글자 | 오류 표시에만 사용 |
| Overlay(Dimmed) | `#1F1F1E` 60% | 팝업 뒤 어두운 막 | 팝업 장면의 뒷배경 |

글자색은 흰 배경 대비 4.5:1 이상인 색만 씁니다. `#888780`은 대비가 부족해서 선에만 씁니다.
